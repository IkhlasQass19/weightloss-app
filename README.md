# Weight Loss Tracker - Expo / React Native

## Build an Android APK

1. Install Node.js 20+ and Git.
2. In this folder run:
   npm install
   npx eas login
   npm run build:apk
3. EAS will build an installable `.apk` using the `preview` profile.
4. Open the build link on your Android phone and install the APK.

## Test locally
npm install
npx expo start

## App contents
- Daily weight, calories, protein, steps, sleep, hunger, energy, and training log
- Local on-device storage
- History view
- Progress to 65 kg
- Your current aggressive-but-moderate coaching targets
